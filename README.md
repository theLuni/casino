# Luni Royal — казино на виртуальные фишки

Премиальное демо-казино в тёмно-фиолетовой люксовой стилистике. **Только виртуальная
валюта (фишки) — никаких реальных денег.** 8 игр, честные коэффициенты, анимации на
canvas, звук, история раундов, промокоды.

## Стек

Vite + vanilla JS (ES-модули), без фреймворков. Каждая игра — отдельный модуль в
`src/games/`. Графика — Canvas 2D + inline SVG с учётом `devicePixelRatio`. Шрифты —
`@fontsource` (Inter / Playfair Display / Unbounded, все с кириллицей). Звуки
синтезируются через WebAudio, внешних ассетов нет.

## Команды

```bash
npm run dev       # dev-сервер (http://localhost:5173)
npm run build     # production-сборка в dist/
npm run preview   # превью собранной версии
npm run selftest  # проверка математики всех игр (RTP, матожидания, Монте-Карло)
npm run smoke     # интеграционный smoke-тест UI на jsdom: лобби → все 8 игр →
                  # пополнение (включая защиту от повторного промокода) → профиль,
                  # баланс никогда не ниже нуля, ни одной ошибки в консоли
```

## Структура

```
index.html               # корневой документ (#bgfx + #app)
src/main.js              # точка входа: шрифты, стили, шапка, роутер, фон
src/styles.css           # дизайн-система: палитра, типографика, компоненты, адаптив
src/core/                # dom, util (RNG, tween), icons (SVG-набор), audio,
                         # promos, store (localStorage), router (hash), fx (боке)
src/games/math.js        # чистая математика всех 8 игр (проверяется селфтестом)
src/games/registry.js    # описания игр, коэффициенты, RTP
src/games/common/        # canvas-обёртка (DPR), общие арท-хелперы
src/games/*.js           # 8 модулей игр: slots, coinflip, dice, roulette,
                         # blackjack, crash, mines, plinko
src/ui/                  # lobby, gameScreen, betPanel, gameArt, profile,
                         # topup, modal, toast, header
scripts/selftest.mjs     # юнит-проверки математики
scripts/smoke.mjs        # интеграционный прогон всего UI в jsdom
```

## Правила и коэффициенты

| Игра | Механика | Выплаты | RTP |
| --- | --- | --- | --- |
| Слоты | 3 барабана, средняя линия | 3×: seven ×150, diamond ×50, bell ×30, star ×20, cherry ×13, bar ×8; 2×: ×0.5 | ≈ 96% |
| Монетка | орёл/решка | ×1.95 | 97.5% |
| Кости | сумма двух костей | <7 или >7: ×2.3, =7: ×5.7 | ≈ 95.8% |
| Рулетка | европейская, 0–36 | чёт/нечёт/красное/чёрное и т.п. ×2, дюжина/колонка ×3, число ×36 | ≈ 97.3% |
| Блэкджек | классика, дилер на 17 | победа ×2, блэкджек ×2.5, ничья — возврат | ≈ 99% |
| Краш | график растёт, можно забрать | множитель до краша, мгновенный краш 3% | 97% |
| Сапёр | 5×5, N мин | множитель за каждую безопасную клетку (×0.99 края) | зависит от стратегии |
| Плинко | 16 рядов, 17 корзин | края ×500 … центр ×0.4–0.5, симметрично | ≈ 96.6% |

## Хранение данных

Баланс, настройки, история операций и раундов, использованные промокоды — в
`localStorage` (`luni-royal:v1`). Промокод срабатывает один раз: повторный ввод
отклоняется. Выход со страницы во время раунда автоматически рассчитывает ставку
(`forceResolve`), баланс не может уйти в минус.

## Промокоды

`WELCOME` +500, `LUNI` +250, `GOLD` +1000, `VIP` +2500, `JACKPOT` +10000.
